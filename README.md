**JavaScript Kickstart** is a beginner-friendly guide to mastering JavaScript fundamentals.
It is designed to help students and aspiring developers build a strong foundation in JavaScript through clear explanations and practical examples.

---

## 📖 About

JavaScript is one of the most popular programming languages used to build dynamic and interactive web applications.

**JavaScript Kickstart helps you:**

* Understand core JavaScript concepts
* Practice syntax with simple examples
* Learn modern ES6+ features
* Build a strong programming foundation

---

## 📚 Topics Covered

This repository includes:

* Introduction to JavaScript
* Data Types
* Operators
* Conditional Statements
* Loops
* Functions
* Variable Scope (`var`, `let`, `const`)
* String Manipulation
* Array Operations
* Objects
* ES6+ Features

## 🛠 Installation

You don’t need any special setup to start learning.

### Option 1: Run in Browser

Open your browser console:

```
Right Click → Inspect → Console
```

### Option 2: Use Node.js

Install Node.js and run:

```bash
node filename.js
```

## 🧠 Example

Here’s a simple example to get started:

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("JavaScript Learner"));
```

Output:

```
Hello, JavaScript Learner!
```

## ✨ ES6+ Highlights

Modern JavaScript features covered:

* Arrow Functions
* Template Literals
* Destructuring
* Spread & Rest Operators
* Default Parameters
* Modules
* Array Methods (`map`, `filter`, `reduce`)

Example:

```javascript
const numbers = [1, 2, 3];

const doubled = numbers.map(num => num * 2);
console.log(doubled);
```
